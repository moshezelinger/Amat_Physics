# דרך ויחידה: פיזיקה ח׳

אתר עצמאי עם 32 תרגילים, שמונה בכל תחום. התלמידים מזהים גוף או מבוקש, בוחרים קשר, מציבים מספרים ויחידות, מחשבים ובודקים משמעות. ההכוונה מצטמצמת אחרי שני התרגילים הראשונים. שאלות מושגיות משתמשות בתרשים ובבחירה במקום לכפות חישוב.

[לתרגול](https://moshezelinger.github.io/Amat_Physics/physics-practice/)

[בקשת המורה המלאה ומעקב המשך, Issue #11](https://github.com/moshezelinger/Amat_Physics/issues/11)

## תחזוקה

ערכו את המקור ובנו מחדש את התוצר. אין לערוך רק את `index.html`.

```sh
node physics-practice/build.mjs
node physics-practice/core.test.cjs
```

אין התקנת תלויות ואין API. `index.html` מכיל את הקוד, העיצוב והגופן המתמטי. אפשר לפתוח אותו ישירות בדפדפן או להוריד מתוך האתר. גופני העברית המקוונים מקבלים חלופת מערכת כשאין רשת.

| קובץ | תפקיד |
|---|---|
| `source/content.js` | 32 תרגילים, שאלות הבנה ומשוב לכל אפשרות |
| `source/core.js` | בניית שלבים, תשובות צפויות, פירוק יחידות למפת חזקות ואימות צמצום |
| `source/app.js` | תצוגה, תרשימים, גרירה, מקלדת, שמירה ופתרון מדורג |

## החלטות מימוש

הנחיות הפתרון והטיפוגרפיה מבוססות על `units-lab/source/lesson.html`. מחזור גרירת Pointer Events מותאם מאותו מקור, עם ניקוי גם באיבוד לכידה, יציאה מהחלון וביטול. גאומטריית ראש החץ מבוססת על P-ARROW. מנגנון חדש ומוגבל לנתונים הצהרתיים נדרש משום שבודק ההמרות של ז׳ אינו בודק שקול, פיתגורס או יחידות מורכבות.

לכל יחידת מידה בצמצום נשמר סימן חזקה לפי מיקומה במשוואה. בהמרת מהירות נשארים גם m בחזקה חיובית וגם s בחזקה שלילית. סימון זוג אינו מצמצם אותו: בדיקת צבעים קודמת לפעולת צמצום נפרדת. לכל שבר זמן או מהירות נשמרים סימונים משלו בחזרה בין השלבים.

בחירת הכיוון החיובי משנה את כל הצבות הסימנים ואת פירוש התוצאה. בפיתגורס מתקבלים שני סדרי הצבה, עם ריבועים תואמים. הרישיות של היחידות נשמרת; `N2` ו־`N^2` מתקבלים כ־`N²`. קלט מספרי מקבל גם סימון מדעי ופסיקי אלפים תקינים.

מיקום התשובה הנכונה משתנה בסדר קבוע בין שאלות. אותו סדר נשמר בכל ביקור כדי שחזרה ושמירה לא ישנו בחירה קיימת. העבודה נשמרת מקומית לפי מזהה תרגיל, ללא שליחה לשרת. שינוי נתון מבטל אישורים תלויים אך שומר את התוכן שהוקלד כדי שניתן יהיה לתקן אותו. שינוי מהותי במבנה הנתונים בעתיד מצריך העלאת גרסת מפתח השמירה ב־`app.js`.

הפתרון המדורג משתמש באותו מודל תשובות כמו התרגול. משוואה נשארת במקומה ונחשפת במספר, יחידה ואיבר נוסף. ההמחשות הפיזיקליות כאן הן תרשימים סטטיים, ולא הנפשות תנועה. אין מידע על תהליך הפיתוח בתצוגת התלמידים.

האתרים הקיימים לא נערכו. לפרסום משלבים את התיקייה הזאת ב־`main`, שממנו פועל GitHub Pages.
