# שבלונה להשוואת טפסים

פתחו את [השבלונה](index.html) בדפדפן. היא מתחילה בשני פריטי דוגמה מסומנים, ומאפשרת לטעון נתוני השוואה חדשים מקובץ JSON. נשמרת חוויית הבדיקה של [המחוון](../../physics-rubric.html): פריט אחד בכל פעם, המלצה קצרה, פרטים לפי בקשה ושמירה להמשך.

## הכנת השוואה חדשה

1. הסוכן קורא את קובצי המקור והטיוטה ומכין עותק של [example.json](example.json). לכל מקור מציינים מזהה, שם וגרסה מדויקת, ובמידת האפשר קישור. לכל שינוי מציינים מקטע מקור, הצעה, סיבה, השפעה, המלצה ומיקום במקורות. מיקום יכול להיות שאלה, סעיף, כותרת או עמוד.
2. מחליפים `review_id`, `version`, `title`, `sources` ו־`items`, ומגדירים `is_demo: false`. לכל פריט מזהה קבוע. `kind` מקבל `changed`, `added`, `removed` או `unchanged`. בתוספת אפשר להשאיר `before` ריק; במחיקה אפשר להשאיר `after` ריק.
3. פותחים את השבלונה וטוענים את קובץ ה־JSON. לחלופין מפיקים עותק HTML עצמאי, עם הנתונים כבר בתוכו:

```bash
python3 templates/form-review/build.py path/to/comparison.json path/to/review.html
```

4. המורה מקבל, מבקש התאמה, משאיר את המקור או דוחה החלטה. בקשת התאמה מחייבת הערה. אפשר לחזור לפריט ולשנות החלטה. טיוטת הערה אינה אישור.
5. בסיום מורידים את ההחלטות כ־JSON ומעבירים אותן לסוכן. אפשר להוריד גם סיכום טקסט לקריאה. הסוכן מוודא התאמה לגרסאות המקור, מעדכן את רשומת העבודה ורק אז מחיל את השינויים שסוכמו.

הקובץ מציג השוואה שהוכנה מראש. קריאת Word או PDF ואיתור ההבדלים נעשים בידי הסוכן לפני הכנת הנתונים. דוגמת הנתונים אינה מכילה שאלות מבחן אמיתי.

## שמירה וחידוש

השמירה האוטומטית מקומית לדפדפן. היא אינה מסנכרנת ציונים או החלטות ל־GitHub. לחידוש במחשב אחר, טוענים את נתוני ההשוואה ואחריהם את קובץ ההחלטות שיוצא. ההחלטות כוללות עותק של נתוני הבסיס, מזהים וגרסאות.

שינוי כלשהו בתוכן ההשוואה או בגרסאות המקורות מבטל התאמה של אישורים ישנים. הכלי מסרב לטעון אותם על בסיס חדש, גם אם מזהה ההשוואה לא השתנה. `deferred` ו־`change_requested` נשארים פתוחים; `accepted` ו־`rejected` נספרים כהכרעות. הבחירות אינן משנות את קובצי המקור אוטומטית.

יש להציג אי־ודאות במקטע המקור בתוך הסיבה או ההשפעה. אין להמציא נתון חסר כדי למלא את השבלונה. אין לשמור נתוני תלמידים או החלטות אישיות במאגר ציבורי.

## בדיקות

```bash
node templates/form-review/core.test.cjs
```

הבדיקות בודקות תקינות מקורות, מזהים וקישורים פנימיים, שימור החלטות, בקשת שינוי עם הערה, ייצוא וטעינה, ודחיית החלטות שהתיישנו לאחר שינוי מקור. אין לשנות את המחוון הקיים כדי ליצור השוואה חדשה.
