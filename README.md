## המצגת: `forces-deck/`

- `project/deck.json`: סדר השקפים, הפרקים, הגופנים ומערכת העיצוב.
- `project/slides/<id>.html`: שקף אחד בכל קובץ. כל שקף הוא `<section>` בגודל 1920×1080 עם רכיבים במיקום מוחלט.
- `project/ds/maslul/tokens.json`: הטוקנים של "מסלול" (צבעים, טיפוגרפיה, מרווחים).
- `assets/`: עותקים מקומיים של התמונות. בשקפים התמונות מופיעות כ־`/_blob/<id>`. הטבלה למטה מראה איזה קובץ מתאים לכל מזהה.
- `tools/`: סקריפטים לבנייה ולתצוגה מקדימה.

### תחביר מיוחד בשקפים

- `data-build-in="fade 2"` / `data-build-out="fade 3"`: הרכיב מופיע או נעלם בהקשה מספר 2 או 3. סוגים: `fade`, `pop`, `rise`.
- `<x-connector x1 y1 x2 y2>`: חץ. הצבע ב־`color`, העובי ב־`border-width`.
- `<aside>`: הערות למרצה.
- `data-transition="magic"`: הנפשת הזזה בין שקפים. רכיבים עם אותו `id` בשני השקפים זזים.
- `<x-embed>`: קנבס עם אנימציה (שקף הפתיחה, שקף הזווית).

### טקסט בעברית

- כל קטע עברי עטוף ב־`&#8235;` בהתחלה וב־`&#8236;` בסוף (RLE ו־PDF). כך מספרים ואותיות לועזיות לא משבשים את הסדר.
- נוסחה ומספר עם יחידה עטופים ב־`&#8206;` (LRM).
- בתוך משפט בעברית המספר צמוד ליחידה: "10N". בתווית של חץ: "10 N".
- אין מקפים ארוכים (— או –) בשום טקסט.

### הכלים

```bash
cd forces-deck
node tools/preview.js "$PWD" out/          # צילום PNG של כל שקף (דורש playwright)
python3 tools/renum.py                     # מספור עמודים וקישורי "במעבדה: תחנה N" לפי deck.json
```

- `gen.py` בונה מחדש כמה שקפים מקוד (פתיחה, ציר אחד, ספר, בדיקת הבנה, כדור, פיתגורס). **הוא דורס עריכות ידניות בשקפים האלה.** אם ערכתם שקף ביד, אל תריצו אותו.
- `maslul.py` ממיר שקף בעיצוב הישן לצבעים של "מסלול". `gen.py` מפעיל אותו אוטומטית.
- `mathfix.py` הופך נוסחה בשורה אחת לשורת רכיבים עם אינדקסים וחץ וקטור.

## הלומדה: `forces-lab/index.html`

קובץ HTML אחד, בלי ספריות חיצוניות חוץ מגופנים מ־Google Fonts. אפשר לפתוח אותו ישירות בדפדפן.

- הצבעים מוגדרים כמשתנים ב־`:root` (לילה) וב־`:root[data-theme="day"]` (יום). כפתור "ערכת יום" מחליף ביניהן.
- כל תחנה היא `<section class="station" id="stN">`. הקוד שלה ב־`<script>` בסוף, בבלוק שמתחיל ב־`/* ---------- Station N`.
- קישור ישיר לתחנה: `index.html#st3`.

## עבודה עם מודלי שפה

1. מודל משנה את הקבצים כאן ופותח Pull Request.
2. אחרי מיזוג, מבקשים מ־Claude לפרסם את הגרסה החדשה לארטיפקט. הוא מעתיק את הקבצים מהמאגר ומפרסם לאותן כתובות.
3. אם מישהו ערך את המצגת ישירות בעורך של Claude, צריך קודם להביא את הגרסה משם למאגר, כדי שהשינויים לא יידרסו.

הנחיות קצרות למודלים נמצאות ב־`AGENTS.md`.
