# דרך ויחידה

לומדת המרות אורך, שטח וזמן לכיתה ז׳, עם 24 תרגילים, 8 בכל נושא. התלמידים בונים משוואה, מסמנים יחידות בצבע, מצמצמים ורושמים תוצאה. ההצבה תומכת בגרירה ובהקלדה; סמל הגודל נשמר לאורך הדרך.

- לפתיחה מקומית: פתחו את `index.html` בדפדפן.
- לאחר שילוב ב־`main`: [פתיחה ב־GitHub Pages](https://moshezelinger.github.io/Amat_Physics/units-lab/).
- כפתור ההורדה בלומדה מוריד את אותו קובץ HTML העצמאי. אין עותק נוסף בשם `with-skill.html`.

## קבצי מקור ובנייה

| קובץ | תפקיד |
|---|---|
| `source/lesson.html` | פריסה, אינטראקציות, הוראות ופתרון מדורג |
| `source/conversion-core.js` | נתוני 24 התרגילים, המרות ואימות צבעים ויחידות |
| `source/questions.js` | שאלות הבנה, מסיחים ומשוב |
| `source/theme.css` | טוקני העיצוב והערכות |
| `source/unit-typography.js` | רינדור יחידות וחזקות |
| `assets/lesson-math.otf` | Latin Modern Math לסמלי גדלים |
| `assets/lesson-math-LICENSE.txt` | הודעות הזכויות ורישיון הגופן |
| `build.mjs` | הפקת ה־HTML העצמאי |
| `core.test.cjs` | בדיקות תוצאות ידועות, צמצום, ניווט ומצבי פתרון |

בתיקיית `units-lab` מריצים:

```sh
node build.mjs
node core.test.cjs
```

הבנייה משתמשת ב־Node ובספריות המובנות שלו, ללא התקנת חבילות. הגופן המתמטי מוטמע ב־HTML, כדי שהאות ℓ תהיה זמינה גם בקובץ שהורד. גופני הטקסט העברי נטענים מ־Google Fonts, עם גופני מערכת כחלופה.

ערכו את המקור המתאים ובנו מחדש את `index.html`; אל תערכו את התוצר הבנוי לבדו. אין כאן קובצי אירוח של Sites, השוואת גרסאות למורה או עותקים של לומדות ישנות.

## שימוש חוזר

[דרך ויחידה: הרגלי פתרון](../.agents/skills/solve-with-units/SKILL.md) מגדיר את עקרונות התרגול, המשוב והמשמעות. להתאמה לכיתה ח׳ בוחרים את רמת התמיכה, התוכן והפעולות הנדרשות; אין צורך לשנות את היקף התוכן הקיים כדי להוסיף יחידה חדשה.

המחשות פיזיקליות מיוחדות, למשל כוחות ומגע בין גופים, נמצאות ב־[מודול ההמחשה האופציונלי](../.agents/skills/solve-with-units/references/physics-visuals.md) וב־[קטלוג הקוד](../docs/CODE_PATTERNS.md). הן אינן חלק חובה מלומדת ההמרות.
