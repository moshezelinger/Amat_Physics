# משימה חדשה, לפי הצורך

המורה יכול לבקש בשפה טבעית; הסוכן משלים את הפרטים הזמינים ואוסף רק מידע חסר שמשנה את התוצר. התבנית אופציונלית ואינה שלב אישור.

קראו את AGENTS.md ואת [מדריך הכתיבה והבנייה](AI_SYSTEM_PROMPT.md). בנו תוצר עובד שאוכל לערוך.

- כיתה ונושא:
- מה התלמידים ידעו להסביר או לבצע:
- ידע קודם ומה תורגל בפועל:
- זמן זמין:
- מצגת, לומדה או שתיהן:
- יחידה קיימת או תיקיית יעד חדשה:
- מקור תוכן או תכנית, אם סופקו:
- בקשות נקודתיות:

התאימו את ההיקף לזמן וליעד, ללא מכסת שקפים או תחנות קבועה. לפני רכיב גרפי בחרו רק את הדוגמה המתאימה מ־[קטלוג הקוד](CODE_PATTERNS.md), והתאימו אותה לעיצוב הפעיל. הציגו תוצר קונקרטי וקישור, עם בדיקות שבוצעו ופרטים שטרם אומתו. אין להמציא גישה לקבצים, התאמה לתכנית רשמית או בדיקת תצוגה.
