# השוואת קבצים והכרעת שינויים

בכל בקשה להשוות קבצים או גרסאות ולהכריע בשינויים, התחילו מ־[שבלונת השוואת הטפסים](../templates/form-review/index.html) והכינו תצוגה מותאמת למקורות הבקשה. [הוראות ונתוני דוגמה](../templates/form-review/README.md) מאפשרים להפיק קובץ עצמאי בלי לבנות שוב את הממשק. [physics-rubric.html](../physics-rubric.html) נשאר המחוון המקורי ודוגמת חוויית המשתמש שהמורה העדיף.

## אופן ההצגה

- הציגו החלטה אחת בכל פעם, עם המלצה קצרה וסיבה. אפשרו להסכים, לבקש שינוי או לדחות החלטה.
- לכל שינוי חברו מקור והצעה, ומה נשמר, נוסף או הוסר. פרטים מלאים, טבלאות ומזהי מעקב נפתחים רק לפי בחירת המורה.
- אפשרו לעבור לפריט מסוים ולחזור להחלטה קודמת בלי לאבד בחירות. הציגו בסוף סיכום קצר של ההחלטות ושל מה שנותר פתוח.
- שימרו החלטות ברשומה ניתנת לייצוא ולטעינה, עם מזהי הקבצים וגרסאות הבסיס. הבהירו אם השמירה מקומית לדפדפן בלבד. רק החלטה שנשמרה והועברה לרשומת העבודה משמשת לביצוע שינוי בקובץ.
- התאימו את נתוני התצוגה למקורות של הבקשה הנוכחית באמצעות `templates/form-review/example.json` ו־`build.py`. אל תשנו את המחוון המקורי כדי להכין השוואה חדשה. הכלי מציג פריטי השוואה שהסוכן הכין מתוך הקבצים; החלטות אינן משנות את הקבצים אוטומטית.

## שימוש בקובץ השמור

פתחו את `physics-rubric.html` בדפדפן. הקובץ עצמאי, והניקוד נשמר בדפדפן או בקובץ JSON שמייצאים ממנו. אל תשמרו ציוני תלמידים או החלטות אישיות בתוך קובץ הדוגמה שבמאגר.

בהשוואת מבחן, דף תרגול והספק הוראה פועלים גם לפי [סקיל המבחנים](../.agents/skills/amat-physics-exams/SKILL.md). רשומת העבודה נשארת מקור האמת; התצוגה האינטראקטיבית מסייעת למורה לעבור עליה בהדרגה.
